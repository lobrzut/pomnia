## Trzy kierunki (wybierz jeden przed generacją)

### 1. Moss Vault

Zamknięty sigil-pamięć: geometryczna „komora” z mchem i srebrzysto-zielonymi krawędziami — metafora lokalnego vaultu, nie kopia run Elder Futhark.

### 2. Birch Thread

Splecione nici pamięci (haft / dream-thread) tworzące delikatny znak na tle ciemnego void — oryginalna geometria, nie gotowy dreamcatcher.

### 3. Dew Sigil

Poranna rosa na liściu + abstrakcyjny labirynt/wesica jako „ślad wspomnienia” — minimalny, czytelny w 32px tray.
