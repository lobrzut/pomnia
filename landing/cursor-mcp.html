Podłącz Cursor do Brain

Wklej URL Brain i token — skopiuj gotowy ~/.cursor/mcp.json z trzema serwerami. Nie potrzebujesz DMG Pomni.

4 kroki

  1. 1URL Brain MCP — port :7862 (np. http://brain.example.local:7862)
  2. 2Token Bearer — dashboard Brain na :7860 → Settings / API tokens → utwórz
  3. 3Skopiuj JSON poniżej → zapisz jako ~/.cursor/mcp.json
  4. 4Cursor: Cmd+Shift+P → „Developer: Reload Window”

Generator mcp.json

Uwaga: sam brain-rag to za mało — potrzebujesz też brain-vault i brain-library. Ten generator zawsze daje wszystkie trzy.

Bez ścieżki /sse — tylko baza. Dashboard tokenów: ten sam host, port 7860.

Token z dashboardu Brain (host:7860). Otwórz dashboard (gdy jesteś w tej samej sieci).

Gotowe — trzy serwery + Authorization. Plik trzymaj prywatnie (chmod 600 ~/.cursor/mcp.json).
Bez tokena remote MCP zwykle nie zadziała. Wklej token z dashboardu :7860, potem skopiuj ponownie.

Plik: ~/.cursor/mcp.json · jeśli plik już istnieje z innymi MCP — użyj trybu merge (tylko obiekt serwerów poniżej w docs).

brain-rag brain-vault brain-library 
{
  "mcpServers": {
    "brain-rag": { "url": "…" },
    "brain-vault": { "url": "…" },
    "brain-library": { "url": "…" }
  }
}

Weryfikacja

  1. ✓Cursor → Settings → MCP — trzy serwery zielone / Connected
  2. ✓W czacie: agent powinien wołać get_user_profile / search_library
  3. !Jeśli widzisz tylko brain-rag — config niepełny; wklej ponownie z tej strony
