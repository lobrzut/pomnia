# Pomnia landing page

Static site for [pomnia.ai](https://pomnia.ai).

- **Entry point:** `index.html` — no build step required
- **Cursor MCP (Mac / no app):** [`cursor-mcp.html`](./cursor-mcp.html) — paste Brain URL + Bearer token → copy full 3-server `~/.cursor/mcp.json`
- **Deploy:** see [`docs/LANDING-DEPLOY.md`](../docs/LANDING-DEPLOY.md)
- **Waitlist:** replace `YOUR_FORM_ID` in the form action with a [Formspree](https://formspree.io) form ID, or rely on the built-in `mailto:waitlist@pomnia.ai` fallback
