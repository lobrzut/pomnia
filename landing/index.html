what it does

Scattered conversations become one memory — and every agent gets to keep it.

Capture

Every conversation from Claude Code, Cursor, Claude Desktop, Antigravity and friends — pulled into one encrypted vault. AES-256-GCM, on your disk, portable as a folder.

Distill

A local model turns raw chat into knowledge: decisions, fixes, dead ends worth remembering. Runs on your GPU via Ollama — no mandatory cloud, no telemetry, no third pair of eyes.

Recall

Every MCP-speaking agent starts the session already knowing you — your stack, your decisions, that bug you fixed in March. One question: search_library. One answer, from everything you've ever discussed.

Claude Code Cursor Antigravity ⇄ pomnia ⇄ Claude Desktop VS Code …

Agents write conversations in; distilled knowledge flows back out — over MCP, the protocol they all already speak. No plugins, no per-tool setup ritual.

why local

Vendor memories are silos. Yours shouldn't be.

ChatGPT's memory won't follow you to Cursor. Claude's won't follow you anywhere else either. Each vendor remembers a version of you — and owns it.

Pomnia inverts that: the memory lives with you, encrypted on your machine, and the agents come to it. Switch tools any day; your context stays — growing a little sharper with every conversation you feed it.
